# Python DSA Practice

My Data Structures and Algorithms practice repository, following along with video tutorials.

## 📚 Structure

```
Python DSA/
├── Programs/          # Practice notebooks (problems only - no solutions)
├── Solutions/         # Reference solutions from tutorials
└── README.md
```

## 🎯 Topics Covered

- Binary Search Trees (BST)
- Heaps & Priority Queues
- More coming soon...

## 🚀 How to Use

1. Open practice notebooks in `Programs/` folder
2. Read the problem statement in each cell
3. Write your solution below the TODO comment
4. Run cells with `Shift + Enter` to test
5. Compare with solutions in `Solutions/` folder if needed

## 🛠️ Setup

```bash
# Clone the repository
git clone <your-repo-url>

# Install Jupyter (if not already installed)
pip install jupyter notebook

# Open notebooks in VS Code or Jupyter
code Programs/
```
